# Equilotl Portable 0.1.0-rc.1

Independent community release candidate based on Equilotl 2.3.0. Not affiliated with Discord, officially with Equicord, or with Team AntiLag.

Adds native unpacked Discord Lite support, verified recovery, precise process diagnostics and controlled Windows x64 distribution. Installer self-update to upstream is disabled; Equicord Repair remains available.

Download the Windows ZIP for GUI/CLI, documentation, required notices and corresponding source. Verify the outer archive with SHA256SUMS.txt; the extracted package also includes per-file hashes. Binaries are unsigned. The separate source ZIP contains the same reviewed source/build scripts.

Recorded host checks: Lite PTB 1.0.1160 and official PTB 1.0.1230. Historical regression: 88 checks and 1,292-file restoration. Publication preparation adds the disabled-self-update regression and upgrades to Go 1.26.10 after vulnerability analysis. Consult the committed validation record and attached source for exact results; hosted workflow success is required for these release assets.

Post-login settings/plugins were maintainer-reported; voice, screen sharing, themes and full manual GUI acceptance are not certified. Unsupported/new host layouts require revalidation. No proprietary Discord/Lite/Equicord binaries, account data or raw private logs are bundled. Client modifications may be subject to Discord's rules.
